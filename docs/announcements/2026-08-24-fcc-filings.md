# The pre-launch pipeline: FCC filings on OEI

**STATUS: This is a draft that has not been published anywhere. It is for Vib's review, and the venue is still undecided (the site changelog, LinkedIn, or both). Every number below was re-measured against production on 2026-11-13, and each one is stated with the count that it was measured over.**

Orbital Economy Intelligence now reads the FCC's space-station filings and shows the applications that have no grant, denial, dismissal or surrender on record, and there are 667 of them. That list is a snapshot, because the FCC's IBFS bulk download, which is where OEI reads it from, has not gained a new filing since 2025-06-18, and OEI does not read new filings from the FCC's ICFS system yet, so some of those applications may have been decided since. A filing can describe a constellation long before it reaches orbit. In the two cases that OEI measured, Starlink Gen1 was filed about 15 months before its first test satellites launched and about 30 months before its first operational batch, and Kuiper was filed about 51 months before its first launch.

From that list, OEI serves validated, machine-extracted specs for 60 of the 136 filings that have harvested documents. The 55 NGSO specs among them carry filed satellite totals that add up to 5,246, of which 2,956 come from a single Boeing V-band filing. Those 55 filings come from 43 systems, and some of them modify the same system, so that figure is a sum of what was filed rather than a count of distinct satellites. Every served value, which includes all 285 orbital planes and all 316 frequency bands, has been re-checked by an independent validator against the exact page of the filing that it cites.

The mechanism is deliberately boring. Schedule S Tech Reports are generated by the FCC's own filing tool in a fixed label-value layout, so extraction is deterministic regex over the extracted text, and no language model is used anywhere in the pipeline. Each extracted value carries the physical page that it was found on, and rows that fail validation are stored but never served. Filings are grouped into dockets that are keyed on callsign, so the SpaceX Gen2 docket, callsign S3069, which holds 28 filings dating from December 2022, of which 19 have been granted and 9 are still pending, reads as one regulatory timeline instead of 28 disconnected rows. The 136 filings with harvested documents hold 1,318 document rows between them, each filing's inventory links straight to the FCC's own copies, and the full methodology is published on GitHub.

The limits are worth stating plainly. Of the 136 filings that have harvested documents, 64 carry a PDF that is named as a Schedule S, but only 60 of those pass the content check that confirms a Tech Report, and those 60 are the filings that serve specs. All four of the others carry a readable document that fails that check, and one of them, a 2016 Boeing filing, has 28 more documents that the FCC's own gateway truncates server-side, so those cannot be checked at all. It's live at orbital.vibcreates.com/filings.
