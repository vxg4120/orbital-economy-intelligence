# The pre-launch pipeline: FCC filings on OEI

**STATUS: DRAFT, not published anywhere. For Vib's review; venue undecided (site changelog, LinkedIn, or both). Every number was live-measured 2026-08-24 and fact-checked against production before drafting.**

Orbital Economy Intelligence now reads the FCC's pending space-station queue: 667 applications with no grant, denial, dismissal, or surrender, and in the two measured cases the filing came 14 months (Starlink Gen1) and 39 months (Kuiper) before first launch. From that queue, OEI serves validated, machine-extracted specs from 60 filings, and the validated NGSO specs alone describe 5,246 proposed satellites. Every served value has been re-checked by an independent validator against the exact page of the filing that it cites.

The mechanism is deliberately boring. Schedule S Tech Reports are generated by the FCC's own filing tool in a fixed label-value layout, so extraction is deterministic regex over the extracted text, and no language model is used anywhere in the pipeline. Each extracted value carries the physical page that it was found on, and rows that fail validation are stored but never served. Filings are grouped into dockets keyed on callsign, so an authorization like SpaceX Gen2, which holds 28 filings since December 2022, with 19 granted and 9 pending, reads as one regulatory timeline instead of 28 disconnected rows.

The limits, plainly: 64 of the 136 filings with harvested documents carry Schedule S Tech Reports, and one 2016 filing has documents that the FCC's own gateway truncates server-side. It's live at orbital.vibcreates.com/filings.
