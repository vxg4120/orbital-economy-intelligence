# FCC Schedule S Deterministic Extraction — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract orbital parameters, frequency bands, and constellation scalars from FCC Schedule S Tech Report PDFs into provenance-tracked tables, with every field carrying a page citation that a validator has independently confirmed.

**Architecture:** Documents are fetched once into a content-hashed blob cache, so extraction is reproducible against bytes we hold rather than a gateway that can change. A pure-function parser turns extracted page text into cited field rows. A validator re-opens each cited page and confirms the value's tokens are physically present before the row becomes publishable. Nothing here uses an LLM: Schedule S Tech Reports are machine-generated by the FCC's filing tool in fixed label-value layout, so a regex parse is both cheaper and exact where a model would be approximate.

**Tech Stack:** Python 3.13, psycopg 3, pypdf, PostgreSQL/TimescaleDB, FastAPI, pytest.

## Global Constraints

- **Migration number is `0020`.** 0012–0019 are taken and applied on the box (0019 landed with the latest-element matview).
- **Apply convention:** `docker compose exec -T oei-api python scripts/migrate.py` from `/root/apps/space/deploy`.
- **`scripts/`, `ingest/`, `api/`, `db/` are baked into the image**, not bind-mounted. A `git pull` alone does not deploy them; `docker compose up -d --build` is required, and verification must be done *inside* the container.
- **Read-only API contract.** `api/deps.get_db` sets `conn.read_only = True`. Extraction writes use a separate connection from `common.db.get_conn`, never the request path.
- **No LLM anywhere in this plan.** Prose fields (deorbit commitments, waiver language) are explicitly out of scope and belong to a follow-up plan.
- **Machine-derived data must never enter headline metrics.** `docs/BUS_BENCHMARKS_METHODOLOGY.md` §5.8 keeps pending FCC applications informational and detail-page-only. Extracted specs inherit that rule.
- **Politeness:** reuse `ingest.runlog.polite_get` pacing conventions. The api-prod gateway intermittently 503s; retry with backoff, record failures rather than crashing a batch.
- **House style:** `ingest/<module>.py` holds pure, network-free, testable logic; `scripts/<verb>_<thing>.py` is the CLI driver that owns the ledger run; `tests/test_<thing>.py` pins our side of the contract using fixture text, never live network.

## Measured corpus facts (established 2026-08-11, do not re-derive)

- `fcc_filing_document` holds 1,307 rows across **136 distinct filings** (avg 9.6 docs/filing, max 133).
- Schedule S: **95 PDFs across 65 filings.** Narratives: 95 docs across 92 filings. Either: 103 of 136.
- Schedule S Tech Reports contain **no** `"Schedule S"`, `"Form 312"`, or `"S4. ORBITAL INFORMATION"` strings — 0 of 3 sampled. Codex proposed those anchors from the blank form; the harvested artifact is the generated report and renders differently. **Real anchors, verified present in 3 of 3:** `OMB 3060-0678`, `312 File Number:`, `Select Orbit Type`, `Operating Frequency Bands`.
- `pypdf` renders these PDFs with label and value on the same line (20 of 20 orbital pairs in the sample), so **no poppler/apt dependency is needed**.
- Narratives contain **no numeric orbital parameters** — apparent matches are prose ("operating at low and very low altitudes"). Do not parse narratives for orbital values.

```sql
-- db/migrations/0020_filing_spec.sql
-- Cited, machine-derived specs extracted from FCC Schedule S Tech Reports.
--
-- Schedule S Tech Reports are generated by the FCC's own filing tool in fixed label-value
-- layout, so these fields are parsed deterministically -- no model, no inference. Every row
-- carries the document it came from, that document's content hash, and the physical page the
-- value appears on, and ingest/spec_validate.py re-opens that page and confirms the tokens are
-- present before is_validated flips true. An unvalidated row is never served.
--
-- Planes are stored raw, one row per orbital plane as Schedule S lists them. "Shell" is a
-- derived grouping and is deliberately NOT stored here; any rollup must cite these rows and
-- record its own grouping rule.
--
-- This layer is machine-derived and stays out of headline metrics, matching the rule that keeps
-- pending FCC applications informational and detail-page-only (BUS_BENCHMARKS_METHODOLOGY 5.8).

CREATE TABLE IF NOT EXISTS fcc_filing_blob (
    file_number   TEXT NOT NULL,
    sys_id        TEXT NOT NULL,
    sha256        TEXT,
    byte_count    BIGINT,
    content_type  TEXT,
    page_count    INT,
    fetch_status  TEXT NOT NULL,           -- ok | http_error | parse_error
    fetch_note    TEXT,
    fetched_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
    PRIMARY KEY (file_number, sys_id)
);

CREATE TABLE IF NOT EXISTS fcc_spec_filing (
    file_number       TEXT PRIMARY KEY,
    sys_id            TEXT NOT NULL,
    doc_sha256        TEXT NOT NULL,
    -- Column names match parse_scalars() output keys exactly (it emits f"{key}_page"), so the
    -- loader is a straight dict-to-column map with no renaming layer to drift out of sync.
    orbit_type             TEXT,           -- NGSO | GSO, verbatim from 'Select Orbit Type'
    orbit_type_page        INT,
    network_name           TEXT,
    network_name_page      INT,
    lifetime_years         NUMERIC,
    lifetime_years_page    INT,
    total_satellites       INT,
    total_satellites_page  INT,
    extractor_version TEXT NOT NULL,
    run_id            BIGINT,
    is_validated      BOOLEAN NOT NULL DEFAULT false,
    extracted_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE TABLE IF NOT EXISTS fcc_spec_orbital (
    file_number       TEXT NOT NULL,
    sys_id            TEXT NOT NULL,
    plane_idx         INT  NOT NULL,       -- ordinal within the document, not an FCC plane id
    apogee_km         NUMERIC,
    perigee_km        NUMERIC,
    inclination_deg   NUMERIC,
    arg_perigee_deg   NUMERIC,
    source_page       INT NOT NULL,
    doc_sha256        TEXT NOT NULL,
    extractor_version TEXT NOT NULL,
    run_id            BIGINT,
    is_validated      BOOLEAN NOT NULL DEFAULT false,
    PRIMARY KEY (file_number, sys_id, plane_idx)
);

CREATE TABLE IF NOT EXISTS fcc_spec_band (
    file_number       TEXT NOT NULL,
    sys_id            TEXT NOT NULL,
    band_idx          INT  NOT NULL,
    service           TEXT,
    freq_low_mhz      NUMERIC,
    freq_high_mhz     NUMERIC,
    direction         TEXT,                -- Transmit | Receive
    source_page       INT NOT NULL,
    doc_sha256        TEXT NOT NULL,
    extractor_version TEXT NOT NULL,
    run_id            BIGINT,
    is_validated      BOOLEAN NOT NULL DEFAULT false,
    PRIMARY KEY (file_number, sys_id, band_idx)
);

CREATE INDEX IF NOT EXISTS fcc_spec_orbital_file ON fcc_spec_orbital (file_number);
CREATE INDEX IF NOT EXISTS fcc_spec_band_file    ON fcc_spec_band (file_number);
```

```python
"""Fetch, hash, and cache FCC filing document bytes, and extract per-page text.

Extraction has to be reproducible against bytes we hold. The api-prod gateway can change or
withdraw an attachment, and a citation that cannot be re-checked is worth nothing on a platform
whose pitch is provenance -- so every document is stored with its sha256 and page count, and the
parser only ever sees text derived from a hashed blob.

pypdf rather than poppler: the Schedule S Tech Reports render label and value on the same line
under pypdf (verified 20 of 20 orbital pairs), so the pure-Python dependency is sufficient and
the runtime image needs no apt packages.
"""

from __future__ import annotations

import hashlib
import io
import logging

logger = logging.getLogger(__name__)

FETCH_TIMEOUT_S = 120


def sha256_bytes(data: bytes) -> str:
    return hashlib.sha256(data).hexdigest()


def page_texts(data: bytes) -> list[str]:
    """Per-physical-page text. Index 0 is page 1; citations are 1-based everywhere else."""
    from pypdf import PdfReader

    reader = PdfReader(io.BytesIO(data))
    return [(page.extract_text() or "") for page in reader.pages]
```

```python
"""Deterministic parser for FCC Schedule S Tech Report PDFs.

These reports are generated by the FCC's filing tool, not typed by applicants, so the layout is
fixed and the values are exact. That makes a regex parse strictly better than a model here: same
cost as reading the file, and no possibility of a plausible-but-wrong number.

Detection deliberately does NOT key on "Schedule S" or "Form 312". Neither string appears in the
generated report (0 of 3 sampled documents) -- those live on the blank form. The anchors below
were read off real harvested documents and are present in 3 of 3.
"""

from __future__ import annotations

import re

EXTRACTOR_VERSION = "schedule_s/1.0"

# Verified present in every sampled Tech Report; absent from narratives.
_ANCHORS = ("OMB 3060-0678", "312 File Number:", "Select Orbit Type")

_SCALARS = {
    "orbit_type": re.compile(r"Select Orbit Type\s+(NGSO|GSO)\b", re.I),
    "network_name": re.compile(r"Space Station or Satellite Network Name\s+(.+?)\s*$", re.M),
    "lifetime_years": re.compile(
        r"Estimated Lifetime of Satellite\(s\) From Date of Launch\s+(\d+(?:\.\d+)?)\s*Years?", re.I
    ),
    "total_satellites": re.compile(
        r"Total Number of Satellites in the active constellation\s+(\d+)", re.I
    ),
}
_NUMERIC = {"lifetime_years": float, "total_satellites": int}


def is_schedule_s(pages: list[str]) -> bool:
    head = "\n".join(pages[:3])
    return sum(1 for a in _ANCHORS if a in head) >= 2


def parse_scalars(pages: list[str]) -> dict:
    out: dict = {}
    for key, pattern in _SCALARS.items():
        out[key] = None
        out[f"{key}_page"] = None
        for page_no, text in enumerate(pages, start=1):
            m = pattern.search(text)
            if not m:
                continue
            raw = m.group(1).strip()
            cast = _NUMERIC.get(key)
            out[key] = cast(raw) if cast else raw
            out[f"{key}_page"] = page_no
            break
    return out
```

```python
# append to ingest/schedule_s.py

_ORBIT_FIELDS = {
    "Inclination Angle": ("inclination_deg", "degrees"),
    "Argument of Perigee": ("arg_perigee_deg", "degrees"),
    "Apogee": ("apogee_km", "km"),
    "Perigee": ("perigee_km", "km"),
}
# Anchored on the unit so prose ("at low altitudes") can never match: the generated report
# always emits "<label> <number> <unit>" on one line.
_ORBIT_LINE = re.compile(
    r"^\s*(Inclination Angle|Argument of Perigee|Apogee|Perigee)\s+"
    r"(-?\d+(?:\.\d+)?)\s+(degrees|km)\s*$",
    re.M,
)
_BAND_LINE = re.compile(
    r"^\s*(?P<service>[A-Za-z][A-Za-z ,'/()-]*?[A-Za-z])\s+"
    r"(?P<low>\d+(?:\.\d+)?)\s*MHz\s*-\s*(?P<high>\d+(?:\.\d+)?)\s*MHz\s+"
    r"(?P<direction>Transmit|Receive)\s*$",
    re.M,
)


def parse_planes(pages: list[str]) -> list[dict]:
    """One row per orbital plane, in document order.

    A plane is closed when a field repeats: the report emits the same four labels per plane, so a
    second 'Inclination Angle' means a new plane started. Shells are NOT derived here -- grouping
    planes into shells is a judgement with its own rule, and it must cite these rows.
    """
    planes: list[dict] = []
    current: dict = {}
    for page_no, text in enumerate(pages, start=1):
        for label, value, unit in _ORBIT_LINE.findall(text):
            key, want_unit = _ORBIT_FIELDS[label]
            if unit != want_unit:
                continue
            if key in current:
                planes.append(current)
                current = {"source_page": current["source_page"]}
            current.setdefault("source_page", page_no)
            current[key] = float(value)
    if current and any(k in current for k in ("apogee_km", "inclination_deg")):
        planes.append(current)
    for idx, plane in enumerate(planes):
        plane["plane_idx"] = idx
    return planes


def parse_bands(pages: list[str]) -> list[dict]:
    bands: list[dict] = []
    for page_no, text in enumerate(pages, start=1):
        for m in _BAND_LINE.finditer(text):
            bands.append({
                "band_idx": len(bands),
                "service": m.group("service").strip(),
                "freq_low_mhz": float(m.group("low")),
                "freq_high_mhz": float(m.group("high")),
                "direction": m.group("direction"),
                "source_page": page_no,
            })
    return bands
```

```python
"""Independent confirmation that a cited page really carries the value cited to it.

The worst failure this pipeline could ship is not a missing altitude, it is a plausible citation
attached to the wrong fact: a reader clicks through, the page does not support the number, and
every other cited figure on the platform becomes suspect. So extraction and validation are
separate passes with separate code paths, and no row is served until this pass has re-opened its
page and found the value's tokens physically present.

Matching is token-boundary anchored on purpose. A naive substring test would validate 25 against
"525.0", which is exactly the coincidence that would let a wrong citation through.
"""

from __future__ import annotations

import re


def _number_forms(value: float) -> list[str]:
    """Renderings the FCC report might use for the same number (525.0 / 525)."""
    forms = {f"{value}"}
    if float(value).is_integer():
        forms.add(str(int(value)))
        forms.add(f"{int(value)}.0")
    return sorted(forms)


def page_supports(page_text: str, value) -> bool:
    if value is None:
        return False
    if isinstance(value, (int, float)) and not isinstance(value, bool):
        candidates = _number_forms(float(value))
    else:
        candidates = [str(value)]
    for form in candidates:
        if re.search(rf"(?<![\d.]){re.escape(form)}(?![\d.])", page_text):
            return True
    return False


def validate_rows(pages: list[str], rows: list[dict], fields: tuple[str, ...]) -> list[bool]:
    """True per row when every non-null field in `fields` is supported by its cited page."""
    out = []
    for row in rows:
        page_no = row.get("source_page")
        if not page_no or page_no > len(pages):
            out.append(False)
            continue
        text = pages[page_no - 1]
        present = [row.get(f) for f in fields if row.get(f) is not None]
        out.append(bool(present) and all(page_supports(text, v) for v in present))
    return out
```

```python
"""Extract Schedule S specs for pending filings whose Tech Report we have not parsed yet.

    .venv/bin/python scripts/extract_filing_specs.py
    .venv/bin/python scripts/extract_filing_specs.py --file-number SATAMD2022063000067
    .venv/bin/python scripts/extract_filing_specs.py --if-stale     # nightly mode

Candidate documents are selected by NAME (a '%sched%' pdf) but confirmed by CONTENT
(schedule_s.is_schedule_s) before anything is parsed, because 558 distinct doc_name values means
naming alone is not trustworthy. Nothing is written for a document that fails the content check.
"""

from __future__ import annotations

import argparse
import datetime as dt
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))

from curl_cffi import requests as cr  # noqa: E402

from common.db import get_conn  # noqa: E402
from ingest import filing_blobs, runlog, schedule_s, spec_validate  # noqa: E402

STALE_AFTER = dt.timedelta(days=6)
PACING_S = 2.0

_TODO_SQL = """
SELECT d.file_number, d.sys_id, d.download_url
FROM fcc_filing_document d
LEFT JOIN fcc_spec_filing s ON s.file_number = d.file_number
WHERE d.doc_name ILIKE '%sched%' AND d.doc_name ILIKE '%.pdf'
  AND s.file_number IS NULL
ORDER BY d.file_number
"""

_SCALAR_COLS = ("orbit_type", "orbit_type_page", "network_name", "network_name_page",
                "lifetime_years", "lifetime_years_page", "total_satellites",
                "total_satellites_page")


def _session():
    """curl_cffi with Chrome impersonation, matching ingest/icfs_documents.py.

    fcc.gov fronts reject python-requests and plain-curl TLS fingerprints. The attachment
    gateway is more permissive than the main properties, but there is no reason to discover
    that the hard way on a batch of 65, and the session is kept warm across the run.
    """
    return cr.Session(impersonate="chrome")


def _fetch(session, url: str) -> bytes:
    """One retry: icfs_documents notes the api-prod gateway intermittently 503s on downloads."""
    last = None
    for _ in range(2):
        try:
            r = session.get(url, timeout=filing_blobs.FETCH_TIMEOUT_S)
            r.raise_for_status()
            return r.content
        except Exception as exc:  # noqa: BLE001 - recorded on the blob row, not swallowed
            last = exc
    raise last


def process_one(session, conn, run_id: int, file_number: str, sys_id: str,
                url: str) -> str:
    try:
        data = _fetch(session, url)
    except Exception as exc:  # noqa: BLE001
        with conn.cursor() as cur:
            cur.execute(
                "INSERT INTO fcc_filing_blob (file_number, sys_id, fetch_status, fetch_note) "
                "VALUES (%s, %s, 'http_error', %s) "
                "ON CONFLICT (file_number, sys_id) DO UPDATE SET fetch_status = 'http_error', "
                "fetch_note = EXCLUDED.fetch_note, fetched_at = now()",
                (file_number, sys_id, str(exc)[:500]),
            )
        return "fetch_failed"

    sha = filing_blobs.sha256_bytes(data)
    try:
        pages = filing_blobs.page_texts(data)
    except Exception as exc:  # noqa: BLE001
        with conn.cursor() as cur:
            cur.execute(
                "INSERT INTO fcc_filing_blob (file_number, sys_id, sha256, byte_count, "
                "fetch_status, fetch_note) VALUES (%s, %s, %s, %s, 'parse_error', %s) "
                "ON CONFLICT (file_number, sys_id) DO UPDATE SET fetch_status = 'parse_error', "
                "fetch_note = EXCLUDED.fetch_note, fetched_at = now()",
                (file_number, sys_id, sha, len(data), str(exc)[:500]),
            )
        return "unreadable"

    with conn.cursor() as cur:
        cur.execute(
            "INSERT INTO fcc_filing_blob (file_number, sys_id, sha256, byte_count, "
            "content_type, page_count, fetch_status) "
            "VALUES (%s, %s, %s, %s, 'application/pdf', %s, 'ok') "
            "ON CONFLICT (file_number, sys_id) DO UPDATE SET sha256 = EXCLUDED.sha256, "
            "byte_count = EXCLUDED.byte_count, page_count = EXCLUDED.page_count, "
            "fetch_status = 'ok', fetched_at = now()",
            (file_number, sys_id, sha, len(data), len(pages)),
        )

    if not schedule_s.is_schedule_s(pages):
        return "not_schedule_s"

    scalars = schedule_s.parse_scalars(pages)
    planes = schedule_s.parse_planes(pages)
    bands = schedule_s.parse_bands(pages)

    scalar_row = {"source_page": scalars.get("orbit_type_page"), **scalars}
    scalar_ok = spec_validate.validate_rows(
        pages, [scalar_row], ("orbit_type", "network_name", "total_satellites"))[0]
    plane_ok = spec_validate.validate_rows(
        pages, planes, ("apogee_km", "perigee_km", "inclination_deg"))
    band_ok = spec_validate.validate_rows(
        pages, bands, ("freq_low_mhz", "freq_high_mhz"))

    with conn.cursor() as cur:
        cur.execute(
            f"INSERT INTO fcc_spec_filing (file_number, sys_id, doc_sha256, "
            f"{', '.join(_SCALAR_COLS)}, extractor_version, run_id, is_validated) "
            f"VALUES (%s, %s, %s, {', '.join(['%s'] * len(_SCALAR_COLS))}, %s, %s, %s) "
            f"ON CONFLICT (file_number) DO NOTHING",
            (file_number, sys_id, sha, *[scalars.get(c) for c in _SCALAR_COLS],
             schedule_s.EXTRACTOR_VERSION, run_id, scalar_ok),
        )
        for plane, ok in zip(planes, plane_ok):
            cur.execute(
                "INSERT INTO fcc_spec_orbital (file_number, sys_id, plane_idx, apogee_km, "
                "perigee_km, inclination_deg, arg_perigee_deg, source_page, doc_sha256, "
                "extractor_version, run_id, is_validated) "
                "VALUES (%s,%s,%s,%s,%s,%s,%s,%s,%s,%s,%s,%s) "
                "ON CONFLICT (file_number, sys_id, plane_idx) DO NOTHING",
                (file_number, sys_id, plane["plane_idx"], plane.get("apogee_km"),
                 plane.get("perigee_km"), plane.get("inclination_deg"),
                 plane.get("arg_perigee_deg"), plane["source_page"], sha,
                 schedule_s.EXTRACTOR_VERSION, run_id, ok),
            )
        for band, ok in zip(bands, band_ok):
            cur.execute(
                "INSERT INTO fcc_spec_band (file_number, sys_id, band_idx, service, "
                "freq_low_mhz, freq_high_mhz, direction, source_page, doc_sha256, "
                "extractor_version, run_id, is_validated) "
                "VALUES (%s,%s,%s,%s,%s,%s,%s,%s,%s,%s,%s,%s) "
                "ON CONFLICT (file_number, sys_id, band_idx) DO NOTHING",
                (file_number, sys_id, band["band_idx"], band["service"], band["freq_low_mhz"],
                 band["freq_high_mhz"], band["direction"], band["source_page"], sha,
                 schedule_s.EXTRACTOR_VERSION, run_id, ok),
            )
    conn.commit()
    return "extracted"


def main() -> int:
    ap = argparse.ArgumentParser(description=__doc__)
    ap.add_argument("--file-number", help="one filing (dashless dump form)")
    ap.add_argument("--limit", type=int, default=None, help="cap the batch size")
    ap.add_argument("--if-stale", action="store_true",
                    help="skip when the last ok extraction is fresher than a week")
    args = ap.parse_args()

    import time

    conn = get_conn()
    try:
        if args.if_stale and runlog.fresh_within(conn, "fcc", "schedule_s_specs", STALE_AFTER):
            print(f"skipped: last extraction within {STALE_AFTER}")
            return 0
        with conn.cursor() as cur:
            cur.execute(_TODO_SQL)
            todo = cur.fetchall()
        if args.file_number:
            todo = [t for t in todo if t[0] == args.file_number]
        if args.limit:
            todo = todo[: args.limit]

        run_id = runlog.start_run(conn, "fcc", "schedule_s_specs")
        session = _session()
        tally: dict[str, int] = {}
        try:
            for i, (file_number, sys_id, url) in enumerate(todo):
                outcome = process_one(session, conn, run_id, file_number, sys_id, url)
                tally[outcome] = tally.get(outcome, 0) + 1
                if i + 1 < len(todo):
                    time.sleep(PACING_S)
        except Exception as exc:
            conn.rollback()
            runlog.finish_run(conn, run_id, rows=0, bytes_dl=0, status="error",
                              notes=str(exc)[:2000])
            raise
        runlog.finish_run(conn, run_id, rows=tally.get("extracted", 0), bytes_dl=0, status="ok",
                          notes=", ".join(f"{k}={v}" for k, v in sorted(tally.items())))
    finally:
        conn.close()

    print("outcomes:", ", ".join(f"{k}={v}" for k, v in sorted(tally.items())))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
@router.get("/{file_number}/spec")
def filing_spec(file_number: str, db=Depends(get_db)):
    """Machine-derived Schedule S specs. Only validated rows are served: a row whose cited page
    did not carry its value is retained in the table for debugging but never returned here."""
    with db.cursor() as cur:
        cur.execute("SELECT * FROM fcc_spec_filing WHERE file_number = %(fn)s AND is_validated",
                    {"fn": file_number})
        summary = cur.fetchone()
        cur.execute("SELECT * FROM fcc_spec_orbital WHERE file_number = %(fn)s AND is_validated "
                    "ORDER BY plane_idx", {"fn": file_number})
        planes = cur.fetchall()
        cur.execute("SELECT * FROM fcc_spec_band WHERE file_number = %(fn)s AND is_validated "
                    "ORDER BY band_idx", {"fn": file_number})
        bands = cur.fetchall()
    return {"summary": summary, "planes": planes, "bands": bands}
```

## Explicitly out of scope

Deferred to a follow-up plan, each for a stated reason:

- **LLM extraction of prose fields** (deorbit commitments, waiver language, amendment-supersedes statements). Needs the 40-filing stratified eval set below before it is trustworthy. Note the measured finding that deorbit sits late in narratives — SpaceX's is on page 16 of 17 — so any page-sampling heuristic must be validated, not assumed.
- **Supersession and lineage modelling.** SATMOD/SATAMD amendments frequently change part of a system; inherited fields must point at the originating filing and be marked `inherited` rather than cited to the amendment. This is its own subsystem and belongs with the existing SCD Type 2 machinery.
- **Shell rollups.** Planes are stored raw here by design. Grouping them into shells is a judgement that needs its own documented rule and must cite the plane rows.
- **A 40-filing eval set** (20 dev, 20 locked), stratified across SATLOA/SATMOD/SATAMD, GSO/NGSO, single-sat/constellation/megaconstellation, and the four coverage combinations. Measure field accuracy, citation precision, recall, and abstention correctness. Citation precision outranks recall for this product.
- **Coverage is bounded and must be published as such.** Schedule S exists for 65 of 136 filings. For the 38 with only a narrative, orbital parameters are probably not in the harvested corpus at all. Publish the coverage split rather than inferring the gap.
